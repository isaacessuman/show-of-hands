# Card fonts

Subsets of open fonts, used only to draw the share-card images (`/api/card/<id>.png`):

- `card-serif.ttf`: Newsreader (Production Type), static 400 instance
- `card-sans.ttf`, `card-sans-bold.ttf`: Hanken Grotesk (Hanken Design Co.), static 500 and 700 instances
- `card-cjk.ttf`: Noto Serif SC (Google / Adobe), static 600 instance, GB2312 level-1 characters

All are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). Family names were changed
to "SOH Serif", "SOH Sans", "SOH Sans Bold" and "SOH CJK" for these modified versions, as the licence asks.
